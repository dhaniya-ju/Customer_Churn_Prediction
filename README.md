📌 **Project Overview**



This project predicts customer churn using **XGBoost Machine Learning.** It analyzes customer details to estimate the probability of churn and classifies customers into Low, Medium, and High Risk levels. An interactive Streamlit web application allows users to enter customer details and receive real-time churn predictions and retention recommendations.

\---



🎯 **Project Objectives**



\- Predict whether a customer is likely to churn.

\- Calculate the probability of customer churn.

\- Identify customers with high, medium, and low churn risk.

\- Help businesses identify high-risk customers at an early stage.

\- Provide recommended actions for customer retention.

\- Build an interactive machine learning web application.

\- Deploy the prediction system as a live web application.

✨ **Features**



1\. Customer Data Input



The application allows users to enter customer information including:



\- Credit Score

\- Gender

\- Age

\- Tenure

\- Balance

\- Number of Products

\- Credit Card Status

\- Active Membership Status

\- Estimated Salary

\- Geography



2\. Risk Classification



Customers are classified into three risk categories:



\- 🟢 **Low Risk** – Customer is unlikely to churn.

\- 🟡 **Medium Risk** – Customer may churn and should be monitored.

\- 🔴 **High Risk** – Customer is likely to churn and requires immediate attention.

🤖 **Machine Learning Model**



The project uses the **XGBoost (Extreme Gradient Boosting) Classifie**r for customer churn prediction.



XGBoost is a powerful gradient boosting algorithm that combines multiple decision trees to create a strong predictive model. It is suitable for classification problems and can effectively capture complex relationships between customer characteristics and churn behavior.
